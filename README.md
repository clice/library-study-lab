# Library Study Lab

Projeto didático para estudo prático de linguagens de programação e conteúdos de Desenvolvimento de Sistemas.

O objetivo deste repositório não é construir imediatamente uma aplicação completa ou pronta para produção. O projeto evolui gradualmente à medida que novos conceitos são estudados.

## Objetivos

- Aplicar na prática os conteúdos estudados.
- Aprender a ler e prever a execução de código.
- Experimentar conceitos antes de resolver questões de concurso.
- Comparar implementações entre diferentes linguagens.
- Manter um histórico do aprendizado com Git.
- Consolidar conteúdos de Desenvolvimento de Sistemas.

## Projeto-base

O domínio escolhido é uma biblioteca pessoal.

Ao longo dos estudos, o sistema poderá representar conceitos como livros, autores, categorias, catálogo, disponibilidade, busca e organização da coleção.

A complexidade será adicionada somente quando o conteúdo correspondente tiver sido estudado.

Este projeto é exclusivamente didático e independente de qualquer aplicação maior de gerenciamento de biblioteca.

## Método de estudo

Para cada unidade:

1. Estudar a teoria da degravação.
2. Aplicar o conteúdo no projeto.
3. Realizar pequenos experimentos.
4. Prever mentalmente a execução do código.
5. Executar e verificar o resultado.
6. Resolver as questões da degravação.
7. Corrigir as questões.
8. Registrar os aprendizados e erros relevantes.
9. Realizar o checkpoint da aula.

## Princípio do projeto

O código deve crescer junto com o conhecimento adquirido.

Não serão introduzidos frameworks, padrões, estruturas ou abstrações apenas para deixar o projeto mais sofisticado quando esses conceitos ainda não tiverem sido estudados.
