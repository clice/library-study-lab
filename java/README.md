# Java

Área reservada para a futura implementação do Library Study Lab em Java.

## Status

Ainda não iniciado.

A estrutura, versão do Java, ferramentas de build, Dockerfile e organização interna serão definidas quando o estudo de Java começar.

## Objetivo futuro

Reimplementar conceitos já vistos no projeto utilizando Java e observar diferenças entre as linguagens.

Entre os conceitos que poderão ser comparados estão:

- variáveis e tipos;
- estruturas de controle;
- métodos;
- arrays e coleções;
- classes e objetos;
- encapsulamento;
- herança;
- polimorfismo;
- interfaces;
- tratamento de exceções.

Nenhum desses tópicos será antecipado antes de aparecer na sequência de estudo.
