# JavaScript

Área do Library Study Lab dedicada ao estudo prático de JavaScript.

## Objetivo

Aplicar progressivamente os conteúdos das aulas de JavaScript em um pequeno sistema de biblioteca.

Não serão utilizados conceitos que ainda não tenham sido estudados apenas para tornar a aplicação mais sofisticada.

## Estrutura

    javascript/
    ├── exercises/
    ├── src/
    └── tests/

### src

Contém o código principal do projeto da biblioteca.

O sistema irá evoluir gradualmente conforme as aulas.

### exercises

Contém pequenos experimentos isolados usados para compreender comportamentos da linguagem.

Por exemplo:

- hoisting;
- escopo;
- operações com arrays;
- diferenças entre métodos;
- trechos semelhantes aos encontrados em questões.

Nem todo experimento precisa fazer parte da aplicação principal.

### tests

Contém testes automatizados.

Eles serão adicionados quando o estudo chegar a um ponto em que sua utilização faça sentido.

## Sequência de estudo

1. Variáveis e Arrays
2. Operadores
3. Condicionais e Laços de Repetição
4. Funções
5. Funções II
6. DOM
7. DOM II
8. BOM
9. BOM II
10. Orientação a Objetos
11. Questões

## Método

Durante cada aula:

1. compreender o conceito;
2. prever o comportamento do código;
3. aplicar no projeto quando fizer sentido;
4. realizar experimentos isolados quando necessário;
5. executar o código;
6. explicar o resultado;
7. resolver as questões da aula.

## Regra pedagógica

Primeiro compreender.

Depois prever.

Depois executar.

Depois explicar.
