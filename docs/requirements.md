# Requirements

Requisitos funcionais do projeto didático Library Study Lab.

Este documento evolui junto com o conteúdo estudado.

Não devem ser adicionados requisitos que exijam conceitos ainda não estudados apenas para tornar o projeto mais completo.

## Escopo inicial

O sistema representa uma pequena biblioteca pessoal.

### Versão inicial

O sistema deverá ser capaz de manter uma coleção simples de livros em memória.

Inicialmente, os dados existirão apenas durante a execução do programa.

Não haverá:

- banco de dados;
- API;
- autenticação;
- framework;
- persistência;
- interface gráfica.

Esses recursos somente serão considerados quando forem pedagogicamente úteis para o conteúdo estudado.

## Aula 01 — Variáveis e Arrays

Objetivos iniciais:

- representar o nome da biblioteca;
- representar uma coleção de livros;
- acessar livros por posição;
- adicionar livros;
- remover livros;
- consultar o tamanho da coleção;
- experimentar diferentes operações com arrays.

Os detalhes da implementação serão definidos durante o laboratório.
